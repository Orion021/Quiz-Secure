Flow: enter URL → iframe opens (70vh) above the URL bar → touch button below (15vh). After iframe loads, 2:30 grace. After that: monitoring phase — the 20s countdown runs only while the button is NOT touched. Touching resets & freezes it at 20s. If it reaches 0 the iframe clears.
Note: If the quiz site is cross-origin (hosted on a different domain), the browser blocks reading the iframe's current URL for security — in that case the Refresh button cannot discover the current question URL and will fall back to reloading the original URL (which may go back to registration).
