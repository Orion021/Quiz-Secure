Behavior: Load a quiz URL. After 2:30 the monitoring phase starts. The Refresh button attempts to reload the current page inside the iframe (so if the student is on a question page it will try to refresh that page).
Important: If the quiz is on a different domain (cross-origin), the browser blocks reading the iframe's current URL — in that case the Refresh cannot discover the exact internal page; use "Open in new tab" to open the current iframe (or original) in a separate tab and refresh there.
